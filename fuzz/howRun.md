# BGP Fuzzing
## Требования

Перед запуском убедитесь, что у вас установлены:

- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)

## Установка и запуск

1. перейдите в папку fuzz :
   ```sh
   cd fuzz
2. Запустите тесты с помощью shell-скрипта:
    ```sh
    ./start.sh
3. Дождитесь завершения тестов.

4. также возможен запуск через pytest
   ```sh
   ./shpytest.sh 
### Где найти результаты
После выполнения тестов отчёт будет сохранён в каталоге output в виде HTML-файла, а также допольнительные данные тестов:

`output/report.html`

Остановка контейнеров
Если нужно вручную остановить контейнеры, используйте:

`docker-compose down`
